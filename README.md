## Project Overview

MediSync HMS is a Full Stack Hospital Management System developed to manage patients, doctors, appointments and billing operations digitally.

The application provides a centralized dashboard and supports complete CRUD operations using REST APIs.

---

## Features

### Patient Management
- Add Patient
- Search Patient
- Delete Patient
- View Patient Records

### Doctor Management
- Add Doctor
- Delete Doctor
- View Doctor Records

### Appointment Management
- Book Appointment
- Patient & Doctor Dropdown Integration
- Delete Appointment
- View Appointment Records

### Billing Management
- Generate Bills
- Automatic Bill Calculation
- Appointment-Based Billing
- Delete Bills

### Dashboard
- Dynamic Statistics
- Dynamic Charts
- Real-Time Record Counts
